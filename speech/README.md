# Phase 10: Text-to-Speech (TTS) Integration Module

## 1. Purpose and Design

This module implements **Phase 10: Classical Text-to-Speech (TTS) Integration** for the academic project:
**“NLP-Based News Article Summarization and Vocabulary Learning System.”**

The objective of Phase 10 is to provide a local, offline speech synthesis interface that converts extractive summaries (generated by Frequency, TF-IDF, or TextRank algorithms in Phases 3–5) into spoken audio.

### Architectural Principles:
1. **Strict Offline Execution**: Uses `pyttsx3` to communicate with the host operating system's native speech drivers (Microsoft SAPI5 on Windows, NSSpeechSynthesizer on macOS, espeak on Linux).
2. **Zero Cloud/AI Dependencies**: No external AI APIs, neural speech models, or cloud TTS services.
3. **Standalone Design**: Decoupled from the summarization algorithms; accepts raw summary strings or file paths.
4. **Deterministic Validation**: Validates rate bounds (50–400 wpm), volume bounds (0.0–1.0), and available voice IDs.
5. **Headless Testability**: Supports dependency injection of mock engines, allowing 100% automated test coverage without requiring physical speakers or audio hardware.

## 3. Python API Usage

The primary interface is `TextToSpeechEngine` (exported via `speech` or `speech.text_to_speech`):

```python
from speech import TextToSpeechEngine

# Initialize the engine
tts = TextToSpeechEngine(rate=175, volume=1.0)

# 1. Query available system voices
voices = tts.get_available_voices()
for v in voices:
    print(f"ID: {v['id']} | Name: {v['name']}")

# 2. Select a specific voice
tts.set_voice(voices[0]["id"])

# 3. Configure rate and volume dynamically
tts.set_rate(160)      # 50 - 400 words per minute
tts.set_volume(0.85)   # 0.0 - 1.0

# 4. Speak text aloud directly
tts.speak("Researchers announced a major renewable energy breakthrough.")

# 5. Synthesize and save to an audio file (.wav)
output_path = tts.save_to_file(
    text="The International Criminal Court issued a formal ruling today.",
    output_path="court_summary.wav",
    overwrite=True,
)
print(f"Saved {output_path.stat().st_size} bytes to {output_path}")

# 6. Stop playback
tts.stop()
```

## 4. Command-Line Interface (CLI)

The module provides a rich command-line tool for standalone terminal usage:

### List Available System Voices
```powershell
python -m speech.text_to_speech --list-voices
```

### Speak an Inline Summary Aloud
```powershell
python -m speech.text_to_speech --text "World leaders signed a multilateral climate agreement in Geneva."
```

### Synthesize from a File and Save Audio
```powershell
python -m speech.text_to_speech --input-file summary.txt --output summary_audio.wav
```

### Custom Speech Rate, Volume, and Voice
```powershell
python -m speech.text_to_speech --text "Electric vehicles gained market share." --rate 160 --volume 0.85 --output ev_news.wav
```

## 5. Supported Audio Formats & Platform Details

- **Supported Extension**: `.wav` (Waveform Audio File Format).
- **Format Rationale**: WAV is the most universally supported, uncompressed PCM format across platform-native TTS drivers (specifically Windows SAPI5).
- **MP3 Notice**: Native `pyttsx3` does not bundle an MP3 encoder; creating MP3 files natively without external C binaries (like ffmpeg/lame) is not supported across all platforms. The module strictly requires `.wav` to guarantee portable, uncorrupted audio files.

## 6. Error Handling & Validation Rules

- **Invalid Text**: Passing non-string inputs raises `TypeError`. Passing empty or whitespace-only strings raises `ValueError`.
- **Speech Rate**: Passing values below 50 or above 400 wpm raises `ValueError`.
- **Volume**: Passing values outside $[0.0, 1.0]$ raises `ValueError`.
- **Unavailable Voice**: Requesting a voice ID that is not installed on the system raises `ValueError` listing valid available voice IDs.
- **Missing Directories**: Providing an output path whose parent directory does not exist raises `FileNotFoundError`.
- **Existing File Protection**: If `overwrite=False` and the destination audio file exists, `FileExistsError` is raised.
- **Empty File Protection**: If the synthesis engine reports success but writes a 0-byte file, `RuntimeError` is raised.
